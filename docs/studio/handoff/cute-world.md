## 0. 一分钟版

1. **App 不用改任何代码**：`WorldMap` 的 props、`onFallback`、`worldEvents`、调试钩子都没变。
2. 画布底色从 `#1c1815` 换成晴空色 `#EAF7FF`，去掉了暗角层（指南 5.9「不加暗角」）。加载 3D 分包时 App 自己的 `world-loading` 占位建议同色（这一条在 lead 的 S0 交接里已经有）。
3. 默认视角变成 GO 式低视角：桌面俯角 24°、手机 30°，玩家站在画面 60% / 64% 高处。**QA 里「离视口中心」类的断言要改成「离构图点」**，读新增的 `camera.anchor`（第 6 节）。
4. 俯角范围 20°–70°（原 35°–70°），M2-07 断言要同步。
5. 低档（手机 / ≤ 4 核）不再开实时阴影：`renderer.shadowMapSize` 报 0（指南 5.3）。

## 2. 契约与新增字段

### 2.1 不变的部分

- `worldEvents`：`recenter` / `resetView` / `pulse` / `celebrate` 的语义不变（演出换成可爱风，见第 5 节）。
- `window.__world`：`tapBeacon` `focusQuest` `setHour` `recenter` `stats` `setView` 全部保留。

## 3. 指南第 5 节落地对照（含偏差与理由）

| 指南 | 落地 | 偏差 / 理由 |
|---|---|---|
| 5.1 色板 | `palette.ts` 原样收录；地面按分类号在着色器里查昼 / 夜两色；建筑五色墙 + 对应屋顶帽；树三色；夜间色同表 | 色板之外补了两个分类：公园大草坪 `#A6DE84`（比公园浅一档，读出草坪与林地）、纪念池池沿 `#E9F2F7` |
| 5.1 昼夜关键帧 | `atmosphere.ts` 的 KEYS 逐行照抄（深夜 / 黎明 / 白天 / 黄昏 / 入夜） | 关键帧强度只决定主光与天光的**比例**；整体亮度每帧归一化到「水平顶面受光 ≈ 1」，因为昼 / 夜两套色板本身就带亮度（夜色乘一盏 0.9 的蓝月光会发黑发紫）。夜里主光往白收 88%、天光去饱和 60%；白天暖阳往白收 45%（实测原样乘到粉彩墙上，受光面蓝通道掉 12–21/255） |
| 5.2 卡通着色 | 建筑、树、地标、玩家共用 `MeshToonMaterial` + 4 阶渐变；地面 Lambert；水与岸线不受光 | 渐变四阶比例按指南（60 / 78 / 92 / 100%），整体 ×0.95：卡通受光面拿整阶亮度，而 Lambert 地面只拿 sin 55° ≈ 0.82，不压屋顶会亮 6%（实测） |
| 5.2 色调映射 | 自定义：峰值 ≤ 0.86 原样输出，以上按 Neutral 同款有理函数柔和压到 1，等比缩放不改色相 | 指南起点是 Neutral。Neutral 从 0.76 就开始压，奶油墙 `#FFF3DE`（R = 1.0）会掉到 `#F0E5D1`，「受光面 ≈ 色板」验收过不了。指南允许「直接退回 Neutral 或轻调色」，这里是更直接的一种；不加后处理 pass |
| 5.2 纹理 | 图标图集 1 张 + 渐变 1 张（+ 高档阴影贴图） | `textures` 读数：桌面 3、手机 2；`textureMB` 32.7 / 0.7 |
| 5.2 建筑着色器瘦身 | 只剩：墙脚 AO（85% → 100%）、墙顶 0.9 m 白色压顶 + 枕面外缘白边、稀疏圆角窗（每面每层 ≤ 2，远处淡出）、夜间窗灯 38% 亮 | 窗格比指南草图大一号（3 × 2.7 m、圆角 1 m、6.4 m 一层）：小窗在默认视距下糊成竖向的点状噪点 |
| 5.2 边缘光 | 玩家白色 fresnel 0.3；徽章 0.3 | — |
| 5.3 光照 | 一盏主光（太阳 / 月亮）+ 半球光；去掉补光；太阳仰角 35°–55° | 高档阴影强度 0.45（暗部 ≥ 65% 亮度、偏天光蓝）；**只有玩具楼高 ≥ 26 m 的楼、地标、玩家投影**——矮楼在 35° 以上的太阳下影子只有几米，省下约 10 万个阴影 pass 三角形；不投影的楼脚下烘一圈环境光遮蔽 |
| 5.3 低档 | 关闭实时阴影；树的软影（1 个 InstancedMesh）、玩家软影（画在精度圈里）、徽章软影（画在地面光圈里）、楼脚 AO 烘进地面顶点 | 软影没有合成同一个网格：徽章 / 玩家的软影直接画在它们本来就有的地面面片里，draw call 一样，省一次逐帧实例更新 |
| 5.4 建筑 | 竖向倒角半径恒为 clamp(0.12 × 短边, 1.2, 4) m（编码几何 + 顶点着色器摆位，零变形）；枕形屋顶；`toyHeight` 压缩；高档每街区 ≤ 3 栋、低档 ≤ 2 栋，缝 ≥ 4 m、退线 3 m；相邻同色 ≤ 2 | 总楼数：高档 10 792 → 5 105（47%）、低档 5 526 → 2 754（49.8%）。高档一栋 40 个三角形、低档 24 个（低档屋顶只有一圈扇形） |
| 5.4 树 | 棒棒糖：圆球树冠 + 6 边树干，三种绿，树冠风摆；中央公园成簇、几条大道两侧成排 | 树冠用 8×4 分段的球（48 个三角形）而不是 icosahedron 细分 1（80 个）：默认视距下树冠十几到几十个像素，平滑法线 + 卡通渐变已读成圆球，省下的三角形让桌面守住 500k。超预算时从外围田野开始抽稀，中央公园最后才动 |

## 6. QA 须知

- **M2-06**（V1 最近 3 个在屏）：GO 式低俯角 + 默认朝北时，从时代广场出发南侧的委托在身后，「最近 3 个」不再全部在屏（实测桌面 3/13、手机 2/13 在屏；前方最近的在构图安全区内）。建议改为「前方（玩家以北）最近的委托在构图安全区内」，或在 V1 读数前 `setView({tilt: 52})` 复现旧口径。
- **M2-07**：俯角断言改为 `[20, 70]`（`camera.tiltRange`）。
- **M2-06 / M2-17 类「离视口中心 ≤ x%」**：改为离 `camera.anchor`。
- `player.screen` / `heightPx` 读的是**画面上的角色**（脚底）。定位一变，角色会从原处走过去（速度随剩余距离递减，1.6 km 约 7 s、几十米约 1–2 s），途中它和定位点不在一处——按定位点裁图会裁到空草地（自查时踩过）。静止时两者重合，所以 M2-05 / M2-17b / V4 这类「在屏」「离构图点」的断言不受影响；需要「走到了再断言」时等 `player.walking === false`；定位点本身看 `camera.target`（recenter 后）。首次出现、断线重连、一下子跳 2.5 km 以上时直接落位，不走。
- 无头 SwiftShader 下桌面高档约 1 fps，一张 1440×900 截图 10–20 s；模拟按真实时间走、单帧 dt 上限 1 s，所以慢帧率下角色走路会多花几帧（真机 60 fps 不受影响）。读 +150 / +400 ms 这类时刻请**先读状态再截图**。
- 默认视角下 q1（时代广场）的徽章就在玩家头顶：玩家站在委托地点时两者重叠是预期行为。
- 徽章一直在慢转（7 s/圈），截图偶尔会碰上侧面朝向；需要正面截图时先 `__harness.focus` / `tapBeacon`（聚焦后停转正对相机），或开「减少动态效果」。

## 10. 已知限制与后续

- **真机帧率与发热未验证**：沙箱只有软件渲染，性能结论以 draw call / 三角形 / 纹理为准。
- 默认视距在时代广场出发时是 796 m（桌面）：GO 式低俯角下，「最近 3 个委托都在画面里」与「主角够大」不能同时满足，取了后者（第 3 节 5.8 行）。
- `WorldMap` 的 `aria-label` 仍写「点击光柱查看委托」——属于「不改名」的契约文本，没动。建议 lead 与 QA 一起改成「点击徽章查看委托」（QA 若用 aria-label 定位需同步）。
- 中景楼群的高度变化偏少（压缩后多在 8–26 m），城外是大片平涂草地：画面干净，但离「密集的手作世界」还差一点。后续可加：街角小广场、低矮的树篱、河上小船（都能实例化，预算有余量：draw call 还有 10+、桌面三角形约 2 万）。
- **委托就在玩家脚下时，徽章会叠在角色头顶**（`final-mobile-day.png`：q1 正在时代广场，徽章恰好转到侧面，看上去像一根白杆插进头里）。原因：徽章不吃世界深度（为了永远不被楼挡住），底座到徽章中心的高度是固定像素，而角色默认约 60–66 px 高。修法建议：给徽章材质传玩家位置，底座离玩家 < 角色半宽时把杆抬高「角色高度 − 杆底」并同步改 CPU 侧的 `badgeCenter` / `pick`；本轮没改，避免交付前再动拾取。
- 徽章 7 s/圈慢转，每圈有两次侧面朝向（指南要求）；如果美术总监觉得侧面那一下太「消失」，可以改成 ±60° 的来回摆动，改一行着色器。
